# 📖 Address Book System (.NET 6 C#)

A simple **Address Book System** built using **C# and .NET 6**, allowing users to manage contacts with CRUD (Create, Read, Update, Delete) functionality.

---

## Features to be added
-  Add new contacts  
-  View all contacts  
-  Update contact details  
-  Delete contacts  
-  Search contacts by name  
-  Store contacts in a file or database  

- 
##  Technologies Used
- **.NET 6**
- **C#**
- **Entity Framework Core (if using a database)**
- **Console Application / ASP.NET Core (as per implementation)**
- **JSON / SQLite / SQL Server (for storage, optional)**
